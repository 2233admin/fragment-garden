# 碎片花园（Fragment Garden）

把来不及整理的内容，种进一座会生长的私人花园。

碎片花园是一款本地优先的个人笔记工具。它帮助你收下零散想法、链接和图片，并在日后把旧内容发展成新的完整笔记。

## 它解决什么问题

我们每天都会遇到值得保存的内容，但不一定有时间立刻整理。

普通笔记工具擅长“存下来”，却很难帮助人重新看见旧内容。笔记越积越多，最后往往变成一个很少打开的仓库。

碎片花园把每篇笔记变成一株植物。花园不仅保存内容，也让旧想法持续出现在视野里，等待被补充、连接和重新发展。

## 四个核心能力

### 随手记录文字、链接和图片

文字可以直接种下。链接和图片会先完成内容整理，成功后才成为正式笔记和植物，不会留下没有内容的空卡片。

### AI 整理为中文笔记

图片和链接会被整理成适合阅读的简体中文笔记。即使原始内容是英文，结果也会以中文为主；产品名、代码、命令和专有名词可以保留原文。

笔记创建后，你仍然可以编辑标题和正文。

### 花园帮助重新发现内容

每篇笔记都会在花园中对应一株植物。你可以从卡片列表寻找内容，也可以在花园中重新遇见过去种下的想法。

花园伙伴会用简单、确定的方式帮助你查看近况、寻找值得重看的内容，并理解花园规则。

### 将旧内容发芽为新笔记

“发芽”不是改写原文，而是从已有内容中发展出一篇新的完整笔记。AI 会读取当前主体笔记和全部用户追加笔记，生成一份可编辑的预览。

只有在你确认后，新笔记和新植物才会被创建。原笔记始终保持不变，并保留两篇笔记之间的来源关系。

## 一次完整的使用流程

1. 记录一段文字，或提交一条链接、一张图片。
2. 内容成为一篇可以阅读和编辑的笔记。
3. 笔记在花园中长成一株植物。
4. 日后想到新内容时，添加一条独立的追加笔记。
5. 回看主体内容和所有补充，选择让它“发芽”。
6. 编辑 AI 生成的预览并确认，得到一篇新的完整笔记。
7. 从新笔记返回来源，也可以从原笔记打开它发芽出的内容。

追加笔记独立保存，不会悄悄改写或合并进原始正文。

## 数据与隐私

数据默认保存在当前浏览器的本地存储中（IndexedDB）。碎片花园目前没有账号系统，也不会自动把整个花园同步到云端。清理浏览器数据或更换设备前，请先导出备份。

完整备份包含笔记、植物、追加内容、来源关系和本地图片。恢复前会先检查文件，确认后才会完整替换当前花园。

链接读取、图片整理和发芽需要第三方服务。应用会在发送相关内容前进行说明，不会把整个花园作为请求内容发送。

API 密钥只用于本地服务端配置，不会写入浏览器数据或备份文件。

## 本地运行

需要 Node.js 20.9.0 或更高版本，以及 npm。

```bash
git clone https://github.com/Zev55555/fragment-garden.git
cd fragment-garden
npm install
npm run dev
```

然后打开 `http://localhost:3000`。

不配置第三方服务时，仍可体验文字笔记、编辑、追加笔记、卡片列表、花园和备份功能。

如需体验链接、图片和发芽，请先复制环境变量模板：

```bash
cp .env.example .env.local
```

按照 `.env.example` 配置需要的服务端参数后，重新启动开发服务。不要提交 `.env.local`。

## 当前 MVP 支持与暂不支持

当前支持：

- 文字、链接和单张图片输入
- 简体中文内容整理
- 内容型笔记与富文本编辑
- 独立追加笔记
- 卡片列表与植物花园
- 花园伙伴
- 发芽预览、编辑和确认
- 新旧笔记的来源关系
- 完整本地备份与安全恢复

当前暂不支持：

- 账号、登录、云同步和跨设备自动同步
- 多人协作和社交
- 移动端适配
- 普通用户语音输入
- 相似笔记与知识图谱
- 多花园和正式像素美术
