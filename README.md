# 碎片宇宙 Fragment Universe

> 把来不及整理的人生碎片，变成一片会回应你的记忆星空。

[立即进入碎片宇宙](https://fragment-universe.vercel.app)

![碎片宇宙主界面](./docs/images/fragment-universe-hero.png)

## 它为什么存在

我们每天都会遇到一些舍不得忘记、却来不及认真整理的东西：一句突然出现的想法，一篇想稍后再看的文章，一张触动自己的图片，或者对旧判断的新补充。

传统笔记工具通常先要求你想好标题、目录和分类。碎片宇宙做了相反的选择：**先让内容留下，再让积累自然显现。**

在这里，每一条成功保存的记录都会点亮一颗真正属于你的星。它不是装饰，也不是随机生成的假内容。你可以重新找到它、打开它，并继续写下后来发生的变化。

## 一条碎片，如何成为一颗星

1. **记录此刻**：写下一段文字，粘贴带有说明的网页链接，或上传一张图片。
2. **等待内容完成**：文字立即保存在本地；链接和图片整理成功后，才会成为正式记录。
3. **点亮记忆星**：保存按钮会在视线中收束、远去，最终落到星空里成为一颗可以直接点击的星。
4. **重新打开**：点击星星，先看到轻量摘要，再展开完整内容。
5. **继续补充**：新的观察不会覆盖原文，而是沿着时间附加；每次补充都会让原来的星更亮一点。

![记录一条新的碎片](./docs/images/fragment-universe-record.png)

## 不是“存进去”，而是“还能回来”

很多记录工具擅长收集，却很少让人愿意重新打开。

碎片宇宙把“回看”放在核心位置：星星的位置始终稳定，点击后先出现克制的小卡片，不打断对整片星空的感受；需要完整阅读时，再平滑展开详情。记录越多，星空的运动会在有限范围内慢慢加快，让积累可见，但不制造焦虑。

![点击一颗星，重新打开一段记忆](./docs/images/fragment-universe-memory.png)

## 支持三种日常输入

### 文字

不要求先想标题。写下正文即可，第一行会自然成为这条记录的识别名称，阅读时不会重复展示。

### 链接

可以直接粘贴网址，也可以粘贴聊天软件生成的“分享文字 + 链接”。产品会自动提取公开网页地址并整理内容，用户也可以补上一句自己的判断。

### 图片

上传一张图片，并按需留下补充。图片会在用户确认后进行中文内容分析；只有分析成功，正式记录和记忆星才会出现。

链接和图片的处理可以转入后台。失败时不会制造一颗空星，也不会假装保存成功。

![链接与图片正在形成记忆](./docs/images/fragment-universe-processing.png)

## 产品做出的几个选择

| 用户真正遇到的问题 | 碎片宇宙的选择 |
| --- | --- |
| 想法出现时没有精力分类 | 不要求目录、标签或知识体系，先完成记录 |
| 收藏很多，却很少重新打开 | 让每条内容成为可直接进入的空间对象 |
| 后来的想法会覆盖或冲淡原文 | 原始内容保留，补充按时间独立追加 |
| AI 容易替用户判断什么重要 | AI 不决定星星的位置、大小、关系或价值 |
| 处理失败容易留下空记录 | 链接和图片成功后才点亮正式内容星 |
| 数据被锁在某个平台里 | 内容默认保存在当前浏览器，并支持完整导出与恢复 |

## AI 在这里做什么，也不做什么

AI 只承担一个清楚、有限的角色：帮助理解用户主动提交的图片。网页链接由专门的内容读取服务处理。

AI 不会替你判断哪段记忆更重要，不会构建关系图，不会决定星星如何排列，也不会把你的内容包装成一套看似聪明却无法解释的知识体系。

**星空表达的是积累，不是算法对你的评价。**

## 数据属于用户

- 不需要注册或登录。
- 正文、补充和图片默认保存在当前浏览器中。
- 可以随时导出完整备份，并在同一产品中预检和恢复。
- 清理浏览器数据或更换设备前，应先导出备份。
- 在线版的链接读取与图片分析已经集成，体验者无需配置 API Key。

当前版本没有账号和云同步，因此不同浏览器、不同设备之间的数据不会自动出现。这是 V1 对隐私、实现成本与产品闭环做出的明确取舍，而不是被隐藏的限制。

## 适合这样的时刻

- 捕捉还没有成形的一句话；
- 留下稍后想重新阅读的网页；
- 保存一张有意义的图片和当时的判断；
- 回到过去的记录旁边，写下新的理解；
- 不想维护复杂分类，但希望看见自己持续积累的人。

## 关于这个作品

碎片宇宙是一款从真实记录困境出发完成的 AI 产品作品。作为 AI 产品经理，我负责了产品定义、核心闭环、Provider 边界、失败策略、交互原型、视觉方向与完整验收，并借助 AI 协作完成工程落地。

这个版本刻意没有加入关系图谱、星座、智能推荐、效率评分或社交系统。V1 只验证一件事：

> 当记录不再是一条条沉入列表的数据，而是成为可以重新接近的星，人是否会更愿意留下它，也更愿意回来看看。

## 当前版本

- 桌面浏览器优先；
- 支持文字、链接和图片；
- 支持回看、追加、删除、备份与恢复；
- 无账号、无云同步、无社交；
- 在线体验已集成链接读取与图片分析服务。
